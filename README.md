# AI-Driven Youth Wellbeing Needs Analysis and Smart Resource Matching System

This project focuses on analysing student mental wellbeing, burnout conditions, behavioural patterns, and academic stress using data science and visual programming techniques.

The system applies:
- Data Cleaning and Transformation
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Wellbeing Risk Scoring
- Smart Resource Recommendation

Technologies used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

The project was developed for the CCS23503 Visual Programming for Data Science course.
